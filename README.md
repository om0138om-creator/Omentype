# 🎨 فونت ستوديو - Font Studio

> تطبيق احترافي لتصميم الصور مع دعم كامل لخصائص OpenType

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Platform](https://img.shields.io/badge/platform-Android%20%7C%20iOS-green)
![License](https://img.shields.io/badge/license-MIT-orange)

## ✨ المميزات

### 🔤 دعم OpenType الكامل
- **Ligatures**: liga, dlig, calt, clig, rlig, hlig
- **Stylistic**: ss01-ss20, swsh, salt, ornm, titl
- **Numbers**: lnum, onum, pnum, tnum, frac, subs, sups
- **Arabic**: init, medi, fina, isol, cswh, rclt, anum

### 🎚️ الخطوط المتغيرة (Variable Fonts)
- دعم محاور التحكم (Weight, Width, Slant, etc.)
- تحكم فوري بالخصائص

### 🖼️ تحرير الصور
- رفع صور من الجهاز أو الكاميرا
- طبقات متعددة
- فلاتر وتأثيرات
- أشكال هندسية

### 📱 أحجام جاهزة
- Instagram (1080×1080)
- Story (1080×1920)
- Facebook (1200×630)
- YouTube (1280×720)
- Twitter (1500×500)

## 🚀 التثبيت

\`\`\`bash
# Clone المشروع
git clone https://github.com/yourusername/font-studio.git

# تثبيت المتطلبات
cd font-studio
npm install

# إضافة منصة Android
npx cap add android

# البناء
npx cap sync android
\`\`\`
